Run
---
Keep the HTML, CSS and assets folder together. Open the HTML in a modern browser.
Internet access is required for Google Fonts, React CDN and Wikimedia category/temple photography.

Design changes
--------------
- Cinematic hero using the supplied wide temple image.
- No diagonal/slant pattern.
- No emoji/icon-based category cards.
- Image-led collection cards.
- Sai Baba imagery for Sai Baba collections and matching temple detail imagery.
- Editorial typography: Cinzel + Cormorant Garamond + DM Sans.
- React ambient particles and pointer-responsive lighting.
- Hero parallax and cinematic zoom.
- Ripple feedback on buttons.
- Scroll reveal for sections/cards.
- Animated home/category view transitions.
- Animated sub-tab indicator.
- Premium sticky search dock.
- Responsive mobile layout.
- Reduced-motion accessibility support.
- Original temple database, search, filtering, visited tracking, edit modal, maps and sharing retained.
